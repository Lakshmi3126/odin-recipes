# Odin Recipes

A simple recipe website built as part of **The Odin Project Foundations** course.

## About

This project demonstrates the fundamentals of HTML by creating a basic recipe website with multiple pages connected using relative links.

## Features

- Homepage with links to recipes
- Three recipe pages
- Recipe images
- Ingredients list
- Step-by-step cooking instructions
- Navigation back to the homepage

## Skills Demonstrated

- HTML Boilerplate
- HTML Elements and Tags
- Headings and Paragraphs
- Lists (`<ul>`, `<ol>`, `<li>`)
- Links (`<a>`)
- Images (`<img>`)
- Relative File Paths
- Project Folder Organization
- Git and GitHub Workflow
